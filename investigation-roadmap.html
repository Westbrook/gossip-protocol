Four matched blocks repeat two application domains. Milestones, probes and scenario executions do not add independent domains.

No calibrated Elo or general superiority follows. The two domains were selected for development, so the reanalysis does not assign a population confidence interval. Its exploratory domain-level sensitivity gives two-sided sign-flip values of 1.0 for acceptance and 0.5 for coverage; domain exchangeability is unestablished, so these are not confirmatory population p-values.

Proposed decision: ten more accepted projects per hundred attempts. A worthwhile gain means the interval’s lower endpoint exceeds +10 percentage points. An upper endpoint below +10 points would rule out that worthwhile gain within the tested task population and execution contract. Anything between remains inconclusive; ruling out a worthwhile benefit does not establish exact equality or universal failure.

A discordant pair is one where only one approach succeeds. Each pair is a different independently sampled task family with one fresh run per arm. Alpha is .025 per claim for two jointly protected hypotheses; the conservative primary interval has at least 97.5% coverage per claim. Direction uses a two-sided exact McNemar test; practical size uses simultaneous exact binomial bounds on the two discordant probabilities.

One hundred pairs could detect a large effect and still leave its useful size unresolved. Eight hundred is one feasible planning point under this conservative method and these assumptions, not a universal minimum. More efficient paired score, profile-likelihood, exact unconditional or melding methods deserve qualification before committing to a large cohort. The choice and sample size must be frozen before outcomes; no repeated extensions until significance.

Statistical design and limits

The calculations sum the finite binomial/multinomial distributions numerically; they do not simulate favorable pilot effects. Alpha .025 allocates an overall error bound of .05 across the separate formation and live-coordination claims. Additional confirmatory endpoints or subgroup claims would need their own prespecified error allocation.

Freeze the task registry, target sampling mixture, controller, endpoint, margin, analysis, sample and stopping rule before confirmatory model calls. If task families repeat or sampling uses fixed strata, replace the independent-pair analysis with a suitable preregistered clustered or stratified method. Failed and bounded runs remain visible. An early funding or infrastructure stop is an incomplete study, not a confirmatory result.

What this comparison can and cannot isolate

All three arms receive the same candidate-blind first-milestone scout evidence; only A/B share the immutable initial candidate pool. Later accepted lineages and model requests diverge naturally. Shared setup is charged once, while imported sources receive fresh arm-specific evaluation. The controller package changes action allocation and adds checkpoint evaluation. Equal offered limits do not imply equal realized compute, and a gain would not identify routing alone as its cause.

Compare repairs on identical cases. Any new failure is a regression, even when the total failure count improves. A changed source file or an additional passing test is not sufficient progress on an unresolved known failure. Preserve failed, bounded and unexecuted trajectories in the planned denominator.

The gossip question still needs a live experiment

Real peers must schedule their own work using durable local state and exchanged evidence.
