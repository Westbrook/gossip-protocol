## Product behavior being implemented

- Migration rotates installation authority only for an actual migration and
  preserves other controls; a stale supported handle fails before obsolete SQL.
- Successful explicit migration clears only its own diagnostic. Ordinary open
  and unrelated successful operations preserve other errors.
- Counter tokens use exact signed 64-bit domains. Each effective transition
  preflights every required increment; exhaustion leaves that transition's
  logical state, diagnostics and files unchanged. No-op and receipt replay
  remain available when no increment is required.
- Portable M1 hash arrays are validated semantically while retaining their
  original strings, including legal whitespace/escapes and deferred bad text.
- Worker diagnostics distinguish live ownership and a matching active claim
  from durable job state. A dead worker cannot remain live merely through rows.
- Backup roots require explicit process-only adoption. Configuration cannot
  silently bind a copied database or reinterpret ownership. Adoption validates
  every registered archive and refuses pending artifacts or changed identities.

The browser must parse, display and resubmit counters through `2**63-1` exactly,
including values above JavaScript's safe Number range. Wire tokens remain JSON
integers; rounded Numbers and quoted string substitutions are not equivalent.
