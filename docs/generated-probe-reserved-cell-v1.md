# Reserved probe cell and source join

`cumulative_generated_probe_accounting_v1.inspect_probe_cell` reconstructs the
complete original after-review reservation before inspecting one planned probe.
It refuses a declined allocation or an allocation without the original child
clock binding. A matching matrix hash or caller summary is insufficient: the
existing original-record reader rechecks financial/build/review/corpus evidence
and the before-review allocation's chronology.

The selected cell must be a generated history, with the exact admitted definition
and ordered value/mechanics checks. The plan must name the same cohort,
trajectory, study, milestone and generation and contain the exact released public
suite. An authored-suite cell cannot be borrowed for a generated probe.

For a candidate-context cell, the target actor must match and the fixed-peer
context is reconstructed from the whole original proposals and reviewer ranks.
For a merged cell, an explicit complete endorsed vector is required. That vector
is only a source-construction request; it is not evidence that conditional
selection chose it. Context IDs use the reconstructed context digest; a merged
candidate ID is `merged`.

The join reads the materialized Git commit from the original source repository
and compares its complete bytes, modes/tree identity and source digest with the
reconstructed context. Merely changing the plan's source hash to match different
Git content is rejected. The supplied candidate Git store must be separate from
the protected project repository, and its accepted head must equal the exact
probe commit. The project accepted branch is not advanced. The result retains
the exact original cell, charge, schedule, plan digest and materialized source.
It appends no record, consumes no slot and dispatches nothing.

This is necessary evidence for future controller admission, not a replacement
for it. Qualified resource envelopes, unique durable execution intent, complete
conditional selection and dispatch integration remain required. Cold joins must
also bind physical evidence and the original clock before observations can guide
selection. No caller-declared cost becomes a measured bound or execution lease.

Offline checks use actual inert Git, externally anchored journals and original
controller readers. Financial proof and mesh seams are synthetic; they are not a
new provider or candidate execution, independent review, live experiment or
statistical sample. The accounting protocol is versioned for this source join;
older retained qualifications retain their original source identity.
