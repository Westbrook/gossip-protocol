portable drivers: raw blob counts and receipt absence after injected rollback;

assume its private storage layout, so they need a declared observation contract

The actual evaluator composition includes the frozen M4 case module and its

## Consumer format and unresolved boundaries

The compact tables declare their column names. `requirement_table` and
`logical_gate_table` preserve the exact compiler denominator.
`obligation_table` binds every unit to its original source hash, JSON pointer
and normalized value hash, with explicit version membership.
`qualification_rule_table` keeps harness authority separate from product
functionality. `retained_gap_note_table` preserves original type and scope.

`evidence_unit_table` distinguishes portable definitions, generic observers,
authored reference assertions and harness controls. JSON pointers describe
returned observations; native Python/JavaScript assertion anchors describe
code that exists, not exported executable Registry selectors.
`partial_mapping_table` joins obligations, evidence units and concise rationale
records. It never assigns a pass, complete assertion-class matrix or automatic
N/A. A case vector or source-level assertion set may still need finer
clause-level decomposition.

Known compatibility hazards are explicit: M4 health projection; v2 stale-instance
precedence; backup-root adoption; worker liveness; and the frozen v1 public
workflow profile. Existing v1 assertions cannot silently grade these v2 changes.
No new v2 behavior is accepted before its independent physical qualification.

The remaining study still requires all four milestones, S4-G/S16-G/O16-G under
healthy and compound-recovery blocks, matched durable orchestration, genuine
peer-local policy, generated distinguishing tests, actual restart and bounded
partition, source-bound promotion, the complete cohort barrier, fresh mandatory
independent observations and later held-out families. This ledger removes none
of those obligations.
